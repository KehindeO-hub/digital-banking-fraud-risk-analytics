# Digital Banking Fraud Risk Analytics

An interactive Power BI portfolio project exploring fraud risk in synthetic digital banking transaction data.

## Project overview

This dashboard was developed to identify fraud patterns, assess financial exposure, and analyse disputes, chargebacks, and fund recovery. It applies fraud investigation techniques and data visualisation to transaction monitoring, fraud trend analysis, and risk assessment.

## Tools

- Microsoft Power BI
- Power Query
- DAX

## Analysis areas

- Fraud patterns and financial exposure
- Transaction monitoring and fraud trends
- Disputes and chargebacks
- Fund recovery

## Data and privacy

The project uses synthetic digital banking transaction data. Do not add real customer records, account details, payment credentials, or confidential banking information to this repository.
